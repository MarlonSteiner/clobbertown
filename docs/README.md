# docs

Images and other material for the repository itself, not for the game. Nothing
in here is loaded at runtime — game assets live in `public/models/`.

## banner.png

The illustration shown at the top of the root README, and the file to upload as
the repository's social preview.

GitHub's social preview is set through the web UI only; there is no API or `gh`
command for it. To set it: **Settings → General → Social preview → Edit → Upload
an image**. GitHub recommends 1280×640, and crops to 2:1.

Record where the artwork came from and its licence before committing it, the
same way `MODELS.md` does for the 3D assets. This repository is public and the
game is intended for commercial release on Steam, so an image whose rights are
unclear is a problem worth catching early rather than late.
